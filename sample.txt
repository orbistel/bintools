REPAIR OPTIONS (fix corrupted files without backup):

  -X <hex>     Hex value that indicates corruption (e.g., 00, FF, 2A)

VIEW/SCAN OPTIONS:

  -c <N>       Limit display to N lines
  -l           List all available formats

Examples:

  hrepair64.exe broken.iso 0 1G -t ISO -X 00 -p
